  IMPROVEMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The app can now update itself directly — no browser, no manual install.

When a new version is available, clicking the update button will:
  1. Download the release zip in the background
  2. Show a progress bar (Downloading → Extracting → Installing)
  3. Replace the app files automatically
  4. Restart the app

The update button is available in two places:
  • Settings → App version → "Update to vX.X.X"
  • Sidebar version badge (appears gold when an update is available)

If no zip file is attached to a release, the button falls back to
opening the GitHub releases page in your browser as before.

  NOTE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The app must be installed in a user-writable folder for the auto-update
to work. If installed under Program Files, Windows will block the file
copy and the update will fail — move the app to a user folder or use
the manual download as a workaround.
