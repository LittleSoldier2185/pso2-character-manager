v1.3.0 — The biggest update yet. Unlimited characters, a completely reworked
variant system, new sync flow, custom title bar, collapsible sidebar, and a
full storage rewrite under the hood.

⚠️ IMPORTANT — DATA MIGRATION
On first launch, the app will automatically migrate your data from the old
format to the new JSON-based storage. This is a one-time process and takes
a few seconds. No data will be lost. Do not close the app during migration.

🚫 No more 50-character limit
The PSO2 salon slot cap is completely gone. Apply as many characters as
you want with no warnings, no slot numbers, and no restrictions.

🔄 Sync from game (reworked)
The old per-card sync badges are gone. A new "Sync from game" sidebar item
glows gold when newer files are detected. Open it to see a full list of
outdated characters with Update / Add new / Ignore actions per entry.
Every variant is now checked individually, not just the main one.

🎨 Variant System Overhaul
Variants now have a card size picker (Small / Medium / Large / XL),
drag-to-reorder support, and a full right-click menu with:
  • Rename, Change thumbnail, Duplicate
  • Set as main, Apply to game, Unapply
  • Export as .pso2char bundle, Delete

🖼️ Custom Title Bar
The native Windows title bar is replaced with a custom dark bar matching
the app's look. Draggable, with a patch notes button and standard
minimize / maximize / close controls.

📌 Collapsible Sidebar
The sidebar now collapses to a compact 56 px icon rail with a smooth
animation. All items show tooltips in collapsed mode.
