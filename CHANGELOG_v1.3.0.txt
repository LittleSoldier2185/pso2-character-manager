v1.3.0 Changelog
=================

Major Updates
=============

PSO2 Salon Limit Removed
-------------------------
- Removed the 50-character slot cap — unlimited characters can now be applied
- Slot numbers removed from character cards (previously showed "Slot 1", "Slot 2", etc.)
- "Applied" button on the detail screen no longer shows a slot number
- Sidebar counter changed from "X / 50 slots used" + progress bar to "X characters applied"
- Applied screen header changed from "X of 50 slots used" + progress bar to "X applied"
- Removed the over-limit warning on the Scan folder import
- "Last applied" sort now orders by applied time instead of slot number

Sync / Update Detection (Reworked)
------------------------------------
Removed:
  - Gold "Updated" badge that appeared on character card thumbnails
  - "File updated in game / Sync" banner that appeared inline on cards
  - Per-card sync dialog

Added:
  - "Sync from game" item in the sidebar (below Scan folder)
      - Glows gold and shows a count badge when updates are detected in the background
  - Sync dialog — opened from the sidebar button
      - Scans all registered characters against the game folder
      - Lists every character with a newer file, showing the modified timestamp
      - Per character, three choices:
          Update   — replaces the stored library file with the game folder version
          Add new  — imports the game folder version as a new character entry
                     (named "[Name] (updated)")
          Ignore   — dismisses the notification for now
      - Rows disappear as you act on them
      - Shows "All files are up to date" when nothing is pending
      - Recheck button to re-scan without closing the dialog

Variant System Overhaul
------------------------
Card size picker
  - Variants section now has a size picker button in the header (same style as
    gallery size picker)
  - Four sizes: Small (72px) / Medium (100px, default) / Large (130px) /
    Extra Large (160px)
  - Thumbnail and card dimensions scale with the selected size

Drag-to-reorder
  - Variants can be reordered by long-pressing a card and dragging it left or
    right
  - Order is saved immediately to disk

Extra info on Medium+ cards
  - At Medium size and above, each variant card shows:
      - The original character filename (e.g. HumanF_01.fhp)
      - The date the variant was last synced to the game folder

New right-click menu actions (organized into three sections)
  Edit:
    - Rename           — renames the variant's display name (inline dialog,
                         same as before but now accessible from the menu)
    - Change thumbnail — opens a file picker to replace the variant's thumbnail
    - Duplicate        — copies all variant files into a new folder and appends
                         "(Copy)" to the display name

  Game:
    - Set as main      — (unchanged, hidden when already main)
    - Apply to game    — (unchanged, hidden when no game folder or already applied)
    - Unapply          — (unchanged, hidden when not applied)

  Export / Delete:
    - Export as bundle — saves the variant (character file + its own thumbnail)
                         as a .pso2char bundle via a save-file dialog
    - Delete           — permanently deletes the variant folder and all its files
                         after a confirmation dialog; blocked if it is the only
                         variant (delete the character instead)

Custom Title Bar
----------------
- Native Windows title bar replaced with a custom dark-themed bar that
  matches the app's color scheme
- App name "PSO2 Character Manager" displayed on the left
- Minimize / maximize-restore / close buttons on the right with hover
  effects (close button turns red on hover, matching Windows convention)
- Title bar is draggable to move the window
- Maximize button icon switches between maximize and restore states

Collapsible Sidebar
--------------------
- Sidebar can be collapsed to a narrow icon-only rail (56 px) and
  expanded back to full width (200 px) with a smooth 200 ms animation
- Collapse: click the « chevron in the sidebar header
- Expand: click the icon or » chevron in the collapsed header
- Collapsed state:
    - All nav items show their icon centered, with a tooltip on hover
      that includes the item name and badge count
    - "Sync from game" shows a small gold dot when updates are pending
      instead of the text badge
    - "Add character" becomes a compact accent + button
    - Section labels and applied count are hidden


Minor Updates
=============

Collections
-----------
- "Edit collection" button moved from the left panel to next to the "Add characters"
  button in the collection detail view
- Search bar added to the Characters tab inside the Edit Collection dialog

Applied to Game Screen
-----------------------
- Added search bar — filter applied characters by name
- Added sort menu — all 6 sort options (Name A-Z, Name Z-A, Newest, Oldest,
  Last applied, Tier)
- Added card size picker — Small / Medium / Large / Extra large
  (shared with home screen setting)

Gallery — Image Context Menu
-----------------------------
Right-clicking any image in the character gallery or the All Gallery screen
shows a context menu with two options:
  - Copy to clipboard — copies the image to the system clipboard so it can be
                        pasted directly into other apps (Discord, Paint, etc.)
  - Set as thumbnail  — sets the image as the character's thumbnail
                        (not shown in All Gallery if the character no longer exists)

Sync from Game — Variant Support
----------------------------------
Previously only the main variant of each character was compared against the
game folder. Now every variant is checked individually.

  - Update detection loops over all variants per character, not just the main one
  - Each variant with a newer game-folder file appears as its own row in the
    dialog, showing: character name · variant name · modified timestamp
  - "Update", "Add new", and "Ignore" act on the specific variant, not the
    whole character
  - Multiple variants of the same character can be updated independently in
    a single session
  - The sidebar badge count reflects the total number of variant-level updates

Random Character Spinner — Variant Support
-------------------------------------------
Variants can now participate in the random spin as individual entries.

Include variants toggle (in the filter panel):
  - OFF (default) — one entry per character (main variant only), same as before
  - ON  — every variant of every character is a separate spin entry; the reel
          can land on e.g. "Mary · Summer outfit" as a distinct result

Variant filter entries (whitelist):
  - Search for a variant by typing a character name or variant name in the
    whitelist search box; results show with kind "variant"
  - Adding a variant to the whitelist force-includes it in the pool even when
    the "Include variants" toggle is OFF
  - The variant is still excluded if it also matches a blacklist entry

Reel card — non-main variants show the variant display name as a second line
            below the character name

Result panel — shows the winning variant name below the character name when
               a non-main variant is landed on

Filter badge in the header now also lights up when the toggle is ON

Open Character Folder
---------------------
- New folder icon button in the character detail screen header
- Opens the character's data folder directly in Windows Explorer
- Available at all times (not just in edit mode)

App Update Checker
-------------------
- On startup, the app silently checks GitHub for a newer release
- If a new version is found, a gold "vX.X.X" badge appears next to the
  version number in the sidebar — click it to open the release page
- Settings → About section added with a "Check for updates" button
    - Shows a spinner while checking
    - If up to date: green snackbar "You're up to date!"
    - If update found: button turns gold "Download vX.X.X" which opens a
      release notes dialog showing what changed, with a Download button
      that opens the GitHub releases page

First-run Setup Prompt
-----------------------
- On first launch with no game folder configured, a one-time dialog appears
  explaining that Apply, Scan, and Sync features require a game folder
- "Open Settings" takes the user directly to the game folder setting
- "Skip" closes the dialog; the prompt never appears again


Bug Fixes
=========

Persistent Sort Setting
------------------------
- The selected sort option is now remembered across sessions
- On next launch, the app restores whichever sort was last used
  (defaults to "Newest first" for existing users with no saved preference)

Sort Fix
---------
- "Tier (S first)" now sorts A-Z within each tier instead of random order
  Applies to: main library, collections, and applied screen


Performance
===========

Skeleton Loading
-----------------
- Skeleton loading screens added to all main list/grid screens so the app
  never shows a blank or empty state while data loads on startup
    - Home screen: 12 shimmer character cards appear while loading
    - Applied screen: same shimmer grid
    - Collections screen: shimmer list tiles while loading
    - Gallery screen: shimmer image grid while loading
- Skeleton cards mirror the real card layout exactly (thumbnail area +
  name row + apply button) to avoid layout shift when real data arrives
- A single animated shimmer highlight sweeps left-to-right across all
  skeleton placeholders in sync (no per-card animation jitter)
- Sidebar tabs now use IndexedStack — switching between screens is instant
  because each screen stays alive rather than rebuilding on every switch
- Character card thumbnails now show a solid background while the image
  decodes from disk instead of a blank flash


Infrastructure
==============

Storage Migration (Hive → JSON)
---------------------------------
The app now stores all data as JSON files in a hierarchical folder structure
instead of the previous Hive binary database. This migration happens
automatically on first launch — no manual steps required and no data is lost.

  - Each character lives in its own named folder containing its .pso2 file,
    gallery images, and a character.json metadata file
  - App settings (accent colour, card size, gallery columns, etc.) are written
    to a human-readable settings.json
  - Tags and collections are stored in tags.json and collections.json
  - Gallery image blur state is now stored per-image inside each character's
    data instead of a shared lookup set
  - Gallery column count is now saved in app settings (persists across sessions)
  - HiveService replaced by DataService throughout all screens and widgets


Renamed
=======

- Sidebar item "Check updates" renamed to "Sync from game"
