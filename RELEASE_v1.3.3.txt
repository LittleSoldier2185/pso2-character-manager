Migration now backs up your old data before creating the new structure.

Before any files are moved or converted, the migration saves a full copy of
your original data to:

  Documents\PSO2CharacterManager\hive_backup\

This includes:
  • All Hive database files (.hive, .lock)
  • Character data files and thumbnails
  • Gallery images (per character)

Each character's files are saved under:
  hive_backup\{CharacterName}_{id}\
  hive_backup\{CharacterName}_{id}\gallery\

The backup folder is not deleted after migration — you can remove it manually
once you have confirmed everything migrated correctly.
