PSO2 Character Manager v1.0.0
First stable release

NEW FEATURES

• Character library — grid view of all your characters with thumbnail,
  name, race, gender, description, and tags. Sort by name, date, or last
  applied. Filter by race, gender, applied status, and collection.

• Apply to game — copy up to 50 character files to your PSO2 game folder
  with one click. Slot tracking (1–50) with a progress bar on the applied
  screen.

• Collections — organise characters into named groups. One character can
  belong to multiple collections. 2×2 preview thumbnail or custom image.

• Tags — create custom tags and assign them to characters for easy
  filtering.

• Import — drag and drop character files and thumbnails from Windows
  Explorer, or scan your PSO2 game folder for unregistered files.

• Export — export any character file to any folder.

• Settings — set a custom save location, configure your PSO2 game folder,
  and choose from 6 accent colours.

PSO2 Character Manager v1.1.0
Tag manager, gallery blur & collection colours

BUG FIXES

• Tag search — search bar tokens now correctly find characters by tag name.
• Favourites sort — primary sort (name, date, etc.) is now fully respected
  within both the favourites and non-favourites groups.
• Scan import crash — imported files are copied into app storage before
  saving, preventing a crash when applying scanned characters.

IMPROVEMENTS

• Tag manager — live search bar, sort menu (name, usage, date), and
  timestamp for time-based sorting.

  sessions and syncs between both galleries.

• Collection colours — cards now tint with the collection accent colour.
  Full HSV colour wheel added — no longer limited to 6 presets.

PSO2 Character Manager v1.2.0
Tier system, character bundles & search rework

BUG FIXES

• Sync detection — update checks now run against all registered characters,
  not just applied ones.
• Sync timer — manual sync check now correctly resets the 30-second auto
  interval to avoid duplicate checks.
• Random spinner — clicking Reroll now rebuilds and spins in one tap
  instead of requiring two.

NEW FEATURES

• Tier rating — rate characters S / A / B / C / D. Tier badge on card
  thumbnail, coloured border per tier, sort by tier, and tier filter in
  the filter panel. Random spinner supports tier whitelisting/blacklisting.

• Character bundles — export and import characters as .pso2char bundles
  (zip with character file, thumbnail, gallery, and metadata). Import
  preview shows contents before committing. Drag and drop .pso2char files
  anywhere in the app.

• Collection detail redesign — left panel with thumbnail, character count,
  and info. Character grid with size picker, sort, and searchable multi-
  select add dialog.

• Card size picker — Extra large / Large / Medium / Small for both the
  library grid and gallery screen. Cards scale displayed info with size.

IMPROVEMENTS

• Search — live filtering by name. Tag filter moved to the filter panel
  with whitelist/blacklist per tag and AND/OR toggle.
• Filter presets — save, name, colour-code, and one-tap restore any
  combination of active filters. Optional persist on close.
• Collections grid — sort button added (name, most characters, newest).

PSO2 Character Manager v1.3.0
No more 50-character limit, variant overhaul & storage rewrite

NOTE: On first launch the app migrates your data from the old format to
JSON storage. This is automatic and takes a few seconds. Do not close
the app during migration.

NEW FEATURES

• No character limit — the PSO2 salon 50-slot cap is completely removed.
  Apply as many characters as you want with no restrictions.

• Sync from game (reworked) — a new sidebar item glows gold when newer
  game files are detected. Open it to see a full list with Update / Add
  new / Ignore actions per entry. Every variant is checked individually.

• Variant system overhaul — card size picker (S/M/L/XL), drag-to-reorder,
  and a full right-click menu: Rename, Change thumbnail, Duplicate,
  Set as main, Apply to game, Unapply, Export as bundle, Delete.

• Custom title bar — dark bar matching the app's look, with a patch notes
  button and standard window controls.

• Collapsible sidebar — collapses to a 56 px icon rail with tooltips.

IMPROVEMENTS

• Applied screen — search bar, sort menu, and card size picker added.
• Gallery — right-click any image to Copy to clipboard or Set as thumbnail.
• Random spinner — variants can enter the spin pool as individual entries.
• Open character folder — folder button in detail screen opens in Explorer.
• App update checker — startup check against GitHub; gold badge in sidebar
  when update available; manual check in Settings → About.
• First-run setup — guides new users to set the game folder on first launch.
• Persistent sort — last-used sort option restored on next launch.

BUG FIXES

• Tier sort — now orders A→Z within each tier instead of random order.

PERFORMANCE

• Skeleton loading screens on all main screens — no blank states on startup.
• Tab switching is now instant (screens stay alive in memory).
• Thumbnail decode flash eliminated.

PSO2 Character Manager v1.3.1
Hotfix for data migration

BUG FIX

• Data migration — migration now correctly reads v1.2.0 data when upgrading.
  The migration screen would complete but silently skip all characters,
  leaving the library empty. Root cause: the migration looked for database
  files in the wrong folder.

  If you ran v1.3.0 and your library was empty:
  1. Close the app
  2. Delete Documents\PSO2CharacterManager\
  3. Install and launch v1.3.1 — migration will re-run correctly
  Your original v1.2.0 files are untouched.

PSO2 Character Manager v1.3.4
In-app auto-update

IMPROVEMENT

• Auto-update — the app can now update itself directly. When a new version
  is available, the update button downloads the release zip, extracts it,
  replaces the app files, and restarts automatically. No browser or manual
  install needed. Falls back to opening the GitHub releases page if no zip
  is attached to the release.

  Note: the app must be in a user-writable folder. If installed under
  Program Files, move it to a user folder or use manual download instead.

PSO2 Character Manager v1.4.0
Tier effects, theme customisation & more

IMPROVEMENTS

• Accent colour — pick any colour from the wheel or choose from 6 presets
  in Settings → Appearance. Changes apply instantly across the whole UI.

• Background colour — 12 presets (6 dark: Midnight, Void, Navy, Dusk,
  Grove, Ember / 6 light: Pearl, Ivory, Mist, Petal, Sage, Slate) or a
  custom colour wheel. Light backgrounds automatically flip to dark text
  and borders. All three background levels are derived automatically.

• Tier borders — unique animated border per tier: S rainbow, A gold
  shimmer, B silver shimmer, C copper shimmer, D plain gray.

• Tier border effects — customisable per tier in Settings → Cards:
  S (Rainbow, Aurora Pulse, Prismatic Sparkle, Holographic)
  A (Shimmer, Pulse Glow, Double Ring, Molten)
  B (Shimmer, Double Ring, Electric Arc, Particle Sparks)
  C (Shimmer, Dashed Rotation, Plasma Wave, Ember Glow)
  D (None, Subtle Pulse, Dim Flicker)

• Per-character border — each character can override its tier border with
  a custom effect and colour. Toggle between "Use tier" and "Custom" in
  the character detail screen.

• Settings redesign — floating overlay dialog with sidebar nav
  (Appearance / Cards / Storage / About). Opens from any page.

• Add as variant — Add Character and both import flows now let you add a
  file as a variant of an existing character instead of a new entry.

• Live search — keyword search now filters as you type. Token pills and
  the Apply button have been removed.

• Applied screen — shows one card per applied variant with its own
  thumbnail and variant name label.

• Tag manager — click any tag card to filter the home screen instantly.
  Unused tags have a sweep button to delete all at once.

PERFORMANCE

• Tier border animations pause when the app loses focus, saving CPU.
